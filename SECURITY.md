# Security Policy

## Supported versions

Security fixes are provided for the most recent published APN release. Older
versions should be upgraded before a report is validated against runtime code.

## Reporting a vulnerability

Please privately report a security vulnerability through
[GitHub private vulnerability reporting](https://github.com/nuanu-ai/agent-payment-node/security/advisories/new).
Do not open a public issue for a suspected vulnerability and do not include
wallet secrets, credentials, private keys, recovery material or live payment
authorization in a report.

Include the affected version or commit, the smallest safe reproduction, impact,
and any relevant platform details. Receipt confirms only that the report was
received; severity, remediation and release status are communicated separately.
