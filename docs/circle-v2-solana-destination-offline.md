# Circle V2 Solana destination offline candidate

`inspectCircleV2SolanaDestinationOffline` is a pure inspection function. Its caller supplies authenticated Circle-attested V2 message bytes and authenticated finalized Solana RPC responses. It never fetches, signs, submits, or admits execution.

The candidate matches the exact message bytes in a top-level `MessageTransmitterV2.receive_message` instruction, the 32-byte nonce and its `used_nonce` PDA, source domain 6, destination domain 5, the V2 TokenMessengerMinter recipient program, the burn body recipient ATA, the canonical USDC mint, and the exact positive finalized ATA delta (`amount - feeExecuted`). It refuses missing or duplicate matching receive instructions. The existing destination candidate enforces finalized successful signature status and transaction, canonical USDC ATA ownership and token program, and unique pre/post balance rows.

The function always returns `bridgeCompletion: false`. It does not decode or bind the `MessageReceived` and `MintAndWithdraw` Anchor CPI events from `meta.innerInstructions`, nor independently validate the Circle attester signature or authenticate RPC provenance. A receive instruction and balance delta alone cannot establish that the matched CCTP invocation caused the mint. No execution path imports this module.

Primary references: [Circle Solana V2 programs](https://developers.circle.com/cctp/references/solana-programs), [receive_message.rs](https://github.com/circlefin/solana-cctp-contracts/blob/master/programs/v2/message-transmitter-v2/src/instructions/receive_message.rs), [Message V2 layout](https://github.com/circlefin/solana-cctp-contracts/blob/master/programs/v2/message-transmitter-v2/src/message.rs), [burn body layout](https://github.com/circlefin/solana-cctp-contracts/blob/master/programs/v2/token-messenger-minter-v2/src/token_messenger_v2/burn_message.rs), and [MintAndWithdraw handler](https://github.com/circlefin/solana-cctp-contracts/blob/master/programs/v2/token-messenger-minter-v2/src/token_messenger_v2/instructions/handle_receive_finalized_message.rs).
