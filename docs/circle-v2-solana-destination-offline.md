# Circle V2 Solana destination offline candidate

`inspectCircleV2SolanaDestinationOffline` is a pure inspection function. Its caller supplies authenticated Circle-attested V2 message bytes and authenticated finalized Solana RPC responses. It never fetches, signs, submits, or admits execution.

The candidate matches the exact message bytes in a top-level `MessageTransmitterV2.receive_message` instruction, the 32-byte nonce and its `used_nonce` PDA, source domain 6, destination domain 5, the V2 TokenMessengerMinter recipient program, the burn body recipient ATA, the canonical USDC mint, and the exact positive finalized ATA delta (`amount - feeExecuted`). It refuses missing or duplicate matching receive instructions. The existing destination candidate enforces finalized successful signature status and transaction, canonical USDC ATA ownership and token program, and unique pre/post balance rows.

`inspectCircleV2SolanaMintEventOffline` additionally requires one `meta.innerInstructions` group indexed to the exact receive instruction. In order, that group must contain the canonical TokenMessengerMinterV2 finalized handler CPI with the same source domain, sender, finality and message body; an SPL token transfer from the handler's custody account to the recipient ATA for the exact net amount; the TokenMessengerMinterV2 `MintAndWithdraw` Anchor CPI event with the ATA, USDC mint, net amount and executed fee; and the MessageTransmitterV2 `MessageReceived` Anchor CPI event with the nonce and body. It rejects missing, duplicated, altered, or reordered matching evidence. Its offline fixtures exercise the byte encoding and failure cases; no real transaction fixture was available for live compatibility verification.

Both functions keep `bridgeCompletion: false`; the mint event inspector also returns `executionAdmitted: false`. The caller must authenticate finalized RPC responses and the Circle-attested message; this code does not independently validate attester signatures or RPC provenance. No execution path imports this module.
